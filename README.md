# SSNTPL Asset Manager — packages

**Internal use — Sword Software N Technologies Pvt. Ltd.**

Built installer packages for SSNTPL-managed devices, published as GitHub Releases so Apple Business
can download them. Each version has its own release and URL; files are never replaced in place.

Packages here are public by necessity and contain no secrets. Source and configuration live in the
private `ssntpl/asset-manager` repository.
